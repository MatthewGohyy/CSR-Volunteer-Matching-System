## 🔌 API Overview

The system provides RESTful APIs organized by functional area:
- **Authentication** - Login, logout, profile management
- **User Management** - Account and profile CRUD operations
- **Request Management** - Create, update, search requests
- **Matching** - Offers, shortlists, matches
- **Categories** - Request category management
