# Setup & Operations Documentation

This directory contains guides for setting up, running, and operating the CSR Volunteer Matching System.

## 📄 Documents

### START_STOP_GUIDE.md
Complete guide on how to start and stop the application, including:
- Development server setup
- Database initialization
- Environment configuration
- Troubleshooting common issues

### DOCKER_GUIDE.md
Docker setup and configuration guide, including:
- Docker Compose setup
- Container management
- Database configuration
- pgAdmin access

## 🚀 Quick Start

1. Read [START_STOP_GUIDE.md](./START_STOP_GUIDE.md) for initial setup
2. Follow [DOCKER_GUIDE.md](./DOCKER_GUIDE.md) for Docker configuration
3. Refer back to these guides when troubleshooting
