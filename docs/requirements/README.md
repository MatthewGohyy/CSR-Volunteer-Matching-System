## 📋 Requirements Overview

The system supports 4 user roles with distinct responsibilities:
1. **User Administrator** - Manages user accounts and profiles
2. **Person-In-Need (PIN)** - Creates and manages help requests
3. **CSR Representative** - Browses requests and provides assistance
4. **Platform Manager** - Manages request categories and platform configuration
