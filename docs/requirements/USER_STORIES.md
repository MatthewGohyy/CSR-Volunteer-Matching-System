# User Stories - CSR Volunteer Matching System

## 📅 Sprint Breakdown

**Total User Stories: 39**
- Sprint 1: 12 stories (Authentication & Basic User/Profile Management)
- Sprint 2: 11 stories (Advanced User/Profile Management & Category Management)
- Sprint 3: 10 stories (Request Management & Shortlisting)
- Sprint 4: 6 stories (History & Advanced Features)

| #3 | User Admin | As a User Admin, I want to create user accounts so that new users can log in. |

## 🏃 Sprint 3: Request Management & Shortlisting
**Duration:** 26 Oct 2025 - 02 Nov 2025  
**Focus:** Complete request CRUD, view tracking, and shortlist functionality

| ID | Role | User Story |
|----|------|------------|
| #15 | PIN | As a PIN, I want to create a request so that I can get matched with a CSR Rep. |
| #16 | PIN | As a PIN, I want to view my requests so that I can monitor their status and progress. |
| #17 | PIN | As a PIN, I want to update my request so that I can update details if something changes. |
| #18 | PIN | As a PIN, I want to delete my request so that I no longer get matched with a CSR Representative. |
| #19 | PIN | As a PIN, I want to search my request so that I can quickly find a specific one. |
| #20 | PIN | As a PIN, I want to view the number of views of my requests so that I can track engagement and progress. |
| #21 | PIN | As a PIN, I want to view the number of shortlists of my requests so that I can track interest from CSR Reps. |
| #26 | CSR Rep | As a CSR Rep, I want to search requests so that I can find appropriate requests that I can provide assistance. |
| #27 | CSR Rep | As a CSR Rep, I want to view requests so that I can understand the needs of the PIN and offer help accordingly. |
| #28 | CSR Rep | As a CSR Rep, I want to save requests so that I can shortlist and find them easily in the future. |
