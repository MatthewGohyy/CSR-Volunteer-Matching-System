# Utility Scripts

This directory contains utility and helper scripts for common development tasks.

## 📄 Scripts

### git-helper.sh
Interactive Git workflow helper with a menu-driven interface for common Git operations:
- Create feature branches
- Commit changes
- Push to GitHub
- Check status
- Pull latest changes
- Complete workflow (commit + push)
- Switch branches
- Merge feature branches
- List branches

**Usage:**
```bash
./scripts/utilities/git-helper.sh
```

**Features:**
- Color-coded output
- Interactive menu
- Branch management
- Commit workflow automation
- Status checking

## 🚀 Quick Start

1. Make the script executable:
   ```bash
   chmod +x scripts/utilities/git-helper.sh
   ```

2. Run the helper:
   ```bash
   ./scripts/utilities/git-helper.sh
   ```

3. Follow the interactive menu prompts

## 📝 Notes

- The script provides a user-friendly interface for Git operations
- All operations are performed on the current repository
- The script includes safety checks and confirmations for destructive operations
